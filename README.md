# Brianna's Choice ❤️

A meal decision wheel for Brianna: spin to pick where to eat, with 5-day fatigue cooldowns, meal history, a food database, and fun restaurant trivia. Built with React, Vite and Tailwind. All data stays in the browser (`localStorage`).

## Run it

    npm install
    npm run dev      # http://localhost:3000

## Deploy

Every push to `main` runs `.github/workflows/deploy.yml`, which builds the app and publishes `dist/` to the `gh-pages` branch. GitHub Pages serves that branch.

## Colours

Forest Green `#183D2B`, Warm Cream `#F5F0E6`, Muted Sage `#A8B5A0`, Muted Gold `#C5A66A`, defined as Tailwind theme overrides in `src/index.css`.
